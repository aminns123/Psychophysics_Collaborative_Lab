# Parameter coverage inventory — 5 November 2026

Integrated baseline: develop e81c4cfa. Generated by inspecting the existing ConfigField, StimulusSpec and experiment declarations; no acquisition values are supplied by this document.

Every experiment input below is visible in Review. Universal setup is edited in Configure; other inputs use Review → Edit selected value. Every slot parameter is visible, including overridden bases. A controller takes precedence over the selected base; genuinely trial-controlled parameters are read-only. Each actual mode is resolved by the real planning/prepare functions, rather than by equality with a default.

Derived: condition lists, phase timing/placements, frame counts, viewport/raster geometry, intensity relationships, threshold estimator and recorded measurements. Fixed: scientific declarations, readiness events, non-editable fields and trial-controlled placements. Internal: RNG state, track counters/history, selected-trial samples, renderer mesh/pixel coverage and caches are not independent scientific inputs. Resolution and provenance expose their relevant outcomes. Original/adaptive/fixed methods can mark declared inputs inactive; inactive values remain visible and validated.

The additive development study ellipse_modular_centre is not one of the established ten; the shared UI also applies to it. Missing required defaults below remain missing and are never invented.
