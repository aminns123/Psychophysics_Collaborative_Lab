# PsyCoLab v0.3.0 — Research preview

**Proposed release notes (not yet published).** Mark this as a **pre-release**: it is a pre-1.0 research version, not a claim of general hardware/acquisition qualification.

## What's new since v0.0.1

- **Read saved data in Python.** The new read-only `load_run(path)` returns named NumPy trial arrays, the run manifest and column definitions. It accepts a `run_NNN` folder or its `trials.tsv`.
- **Compatible analysis access.** Reads by column name, preserves optional additional columns, and refuses unknown numbered trial schemas rather than guessing meanings. Original acquisition files are never rewritten.
- **Researcher documentation.** A copyable example is available in [Analysing run data](../ANALYSING_RUN_DATA.md) and through **Learn / Help**.
- **Consistent release numbering.** Python package version `0.3.0` corresponds to the proposed GitHub tag `v0.3.0`. The historical `v0.0.1` archive still contains internal version `0.2.2`.

```python
from psychophysics_lab.data.reader import load_run

run = load_run(r"C:\path\to\run_001")
contrast = run["trials"]["presented_display_contrast"].astype(float)
correct = run["trials"]["correct"].astype(int)
```

## Compatibility and testing

**No changes to scientific acquisition:** the fixed **20-column** trial-schema-1 writer, adaptive/staircase mathematics, timing, calibration requirements and participant stimulus presentation are unchanged. Reader support for additional columns does **not** yet enable experiments to record arbitrary new columns.

On 24 October 2026, the user reported **25 passing focused reader/run-integrity tests** on a Windows Python 3.11 installation, with one warning about a separately changed local experiment requiring a readiness retest. Full-suite results and physical laboratory acceptance are **not** established by those tests. Recheck the final tagged commit before publishing.

## Installation and limitations

Use **Python 3.11** and the supported Windows launcher `run_psycolab.bat`. GitHub automatically offers **Source code (zip)** and **Source code (tar.gz)**, which are source snapshots—not an installer or a calibrated laboratory setup. Extract to a **new folder**; never overlay a ZIP on a modified Git checkout. Local configuration, monitor calibration and acquisition data require separate handling.

Lab-local scientific Python still belongs on private branches/forks until the external extension loader is implemented. No software licence has yet been selected; public downloads do not grant general redistribution rights.
