### Equations and rendering

* Geometry uses `L = 2 d tan(theta/2)` and its inverse for finite spans; display
  pixels use measured dimensions/resolution with independent x/y pitch and
  `atan(pixel_position/d)` angular coordinates. Pixel rounding and flat-screen,
  fixed-viewpoint assumptions remain explicit. Nyquist carrier checks cannot
  prove that a hard aperture edge or the optical image is adequately sampled.
* Bright marks use `I = B + C_headroom(1-B)`. Line/ellipse studies retain raw
  `Delta_I` in their recorded fields and convert to `C_headroom = Delta_I/(1-B)`
  only when preparing `ProbeLine`. Gratings use `B + (C_pp/2) envelope sin(...)`;
  legal symmetric modulation is `C_pp <= 2 min(B,1-B)`. These units differ from
  measured optical Weber or Michelson contrast.
* Simple line/square/rectangle/ellipse/annulus definitions, rotation signs,
  offsets, lengths versus semiaxes and intensity commands agree with independent
  scalar evaluations. `EllipseRing` subtracts a fixed axial inset from each
  semiaxis: it is not a constant-normal-thickness ellipse.
* `SinusoidalGrating`, `GaborPatch` and `TeachingGabor` retain their declared sine
  versus cosine carriers, angular phase/orientation and historical Gaussian
  semantics. Explicit hard/faded apertures remain opt-in. The two CSF classes
  have different envelopes and must not be reported as visually equivalent.
* `GaussianDot`/`GaussianFixationSpot` truncate at four sigma. The legacy
  `GaussianFixation`/`GaussianSceneFixation` intentionally cap the peak at one;
  that declared legacy appearance is preserved. `FixationCross`, legacy probe/
  example line classes and `ResearcherVerticalLine` keep their declared patch/
  geometry behavior. Deliberate patch or viewport cropping is not automatically
  a defect; target visibility and intended support need researcher inspection.
* `ComposedScene` has active drawing consumers; independent `EllipseRing`,
  `ProbeLine`, `FlankerGrating` and fixation layers serve official protocols.
  For alpha `a` and foreground `F`, a patch already on B is `(1-a)B+aF`.
  Ordered over gives `(1-a)D+aF`; add applies the already weighted deviation
  `patch-B` once. Independent random-array checks agree. Gamut violations are
  rejected instead of clipping scientific pixels. Probe fractional pixel area
  integrates to continuous width × length for shifted subpixel cases.

`test_baseline_render_oracles.py` supplies scalar equations independent of the
production helper functions, 86 points per point-renderer, three probe area
cases and 40 random two-layer comparisons in both modes. Existing independent
historical pixel and explicit-envelope tests remain mandatory as complementary
evidence, rather than replaced by the new checks.

### Adaptive rules, timing and records

Consecutive-correct/incorrect streaks reset appropriately. Modern initial
presentation counts as a presentation; optional initial one-down is explicit.
Reversals depend on changes in **actual numeric movement**, ignoring holds and
clipped plateaus. The turning value is the presented strength. Log increments
and decrements retain their signs, bounds and representable positive floor;
zero catch levels and finite teaching stopping have different semantics from
converged threshold estimation. Complete conditions require all their configured
tracks; an accepted response ceiling or abort never fabricates completion.

The nominal accuracy-target fields are local approximations, not a finite-step
guarantee. García-Pérez's [original study](https://pubmed.ncbi.nlm.nih.gov/9797963/)
demonstrates step-size/psychometric dependence and short-staircase bias. Optional
paired-step recommendations retain their restricted assumptions. A constant-
accuracy `TeachingObserver` checks execution, not unbiased human thresholds.

Frame-counted presentation rounds requested ms to at least one refresh frame.
Images prepare before timed phases. Software timestamps follow flips; late
response keys cannot rescue an expired response, stale/held keys are filtered
and Escape/close aborts. Actual photon timing and keyboard/audio latency are
unverified. Independent instrument measurement is required; see the original
[timing study](https://pubmed.ncbi.nlm.nih.gov/33005482/), which used external
timing hardware. Digital contrasts also need an explicitly measured transfer
and justified task interpretation; [Pelli and Bex](https://pubmed.ncbi.nlm.nih.gov/23643905/)
discuss forced-choice threshold measurement, not certification of this platform.

Accepted trials, journals, histories, state and manifest remain distinct.
Strict `validate_run` checks saved invariants; public `load_run` deliberately
preserves historical/extra columns without executing old experiment Python.
Derived TSV/JSON/PNG exports are versioned below each run and cannot rewrite
its canonical inputs. Partial/error statuses remain visible. The new primary
report's SHA256 inputs include manifest, trials and resolved protocol.

## Baseline scope, installation and remaining gates

Supported software target remains **Windows 11 x64, Python 3.11**. This audit's
new source environment uses existing CPython 3.11.9 with pinned development
wheels, not the separately approved conda-forge 3.11.15 locked deployment.
The first actual `PsyCoLab.bat --repair` setup succeeded in the isolated clone;
it supplies no laboratory qualification. Native tests use real batch/C# hosts,
disposable environments and headless TUI drivers. Simulated missing-Python,
offline and interruption states do not uninstall Python, disconnect the machine
or constitute a clean operating-system acceptance.

For users: update to a reviewed complete source snapshot, then double-click
**PsyCoLab.bat**. Choose **Check / Repair PsyCoLab**, read the action and confirm
it; install x64 Python 3.11 if requested. Supported unqualified legacy-record
repair preserves the original environment, installs/verifies a separate
replacement and returns to the menu. Choose **Launch PsyCoLab**. Healthy reuse
does not reinstall packages. **Python Workspace** uses the verified interpreter;
`exit` returns to the menu. No automatic Git update or acquisition replay occurs.
Use the [recovery/restore guide](SOURCE_INSTALLATION_RECOVERY.md) for retained
backups, logs and retry. Qualified/managed/unknown installation records are
preserved and refused rather than silently converted to development status.

Before stable publication, complete the independent supported-workstation and
human researcher acceptance plus intended old/new release update/rollback,
rights/attribution, required-check administration and explicit version/owner
approval in Issue #82. Stage 3's approved environment already exists; its old
dated roadmap wording is not an instruction to redesign installation again.
No installer, version bump, merge, tag or release is produced by this audit.

For human measurement, each laboratory still needs measured screen dimensions/
eye distance and display binding, photometric transfer/gamut/gamma/HDR/color
pipeline/precision, sampling at selected eccentricities, photon/refresh timing,
response-device and acoustic latency where used, and protocol validity including
catch/ambiguous levels, lapse/bias/estimator precision and fixation requirements.
Software Ready and recorded researcher overrides do not create those measurements.

Deferred features: further B-section shortening; automatic retirement of old
entry names after their documented acceptance window; generalized source
namespace/import changes; new psychometric fits/estimators; automatic scientific
metadata renaming; wheel-only resource packaging and public guided-installer
distribution. None is needed to repair the verified derived-report defect.
