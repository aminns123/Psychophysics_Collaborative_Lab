# Researcher acceptance of luminance mappings

The Luminance screen now has **Accept luminance values → Timing**.

1. Review the saved digital intensity and luminance pairs.
2. Add or correct readings if needed, selecting their actual source.
3. Choose Accept. Changes are saved in the normal active dataset; unchanged mappings are not rewritten.
4. Continue to Timing or return to the experiment's Review screen.

Acceptance records that the researcher has chosen this mapping for the selected display. It is **not** independent measurement or physical verification. Test/example readings remain labelled test data and cannot qualify real human acquisition.

There is one active dataset for the display and history of earlier datasets. A materially changed mapping or display requires fresh review and acceptance. The physical verification screen remains separate.
