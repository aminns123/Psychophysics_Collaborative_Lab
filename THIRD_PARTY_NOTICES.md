separately by supporting viewers. A future distribution of the font files
must retain the applicable SIL Open Font License 1.1 notice.
[Fira Code 6.2 licence](https://github.com/tonsky/FiraCode/blob/6.2/LICENSE)

inspected font resources contain no embedded font programs.
