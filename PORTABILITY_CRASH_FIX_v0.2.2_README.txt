PsyCoLab v0.2.2 portability-check and crash-diagnostics correction
==================================================================

Why this small follow-up exists
-------------------------------
The v0.2.1 portability checker correctly detected tracked local artefacts, but
it also scanned its own detector expressions. That caused false positives for
macOS/Linux home-path patterns and the developer-name detector.

This update fixes that self-triggering behaviour.

It also strengthens the requested failure behaviour:
- ordinary Python/TUI/experiment-launch exceptions are printed in full;
- a timestamped psycolab_error_*.log report is saved where possible;
- Python faulthandler is enabled during execution so a low-level/native Python
  failure can leave psycolab_fatal_*.log;
- the Windows BAT launcher explicitly pauses after every non-zero application
  exit and tells the user where to look for the logs.

No psychophysical/scientific behaviour is changed by this patch.

Applying after cleanup_git_tracking.py
--------------------------------------
The many staged `.venv/... deleted` entries you currently see are EXPECTED.
`git rm --cached` removed them from Git tracking, not from your local disk.
Do not restore those staged deletions.

1. Extract this ZIP over the root of Psychophysics_Collaborative_Lab.
2. Run:

       .venv\Scripts\python.exe scripts\portability_check.py

3. The checker should now only report genuine remaining issues. If the .venv and
   .vscode removals are still staged, they no longer count as tracked files.
4. Run tests if desired:

       .venv\Scripts\python.exe -m pytest

5. Review `git status`, then stage the new/modified v0.2.2 files as well as the
   already-staged removals and commit them together.

Crash reports
-------------
On a normal Python exception, PsyCoLab writes a `psycolab_error_*.log` file.
The selected data folder's `.psycolab_logs` directory is preferred once known;
the repository-local `.psycolab_logs` directory is the fallback.

For a low-level/native failure, `psycolab_fatal_*.log` is a best-effort fallback.
It is removed automatically on a clean exit and remains after abnormal exit.

All `.psycolab_logs` folders are local diagnostics and are ignored by Git.
